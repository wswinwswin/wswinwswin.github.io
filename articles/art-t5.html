Agent 的“应用商店”来了：Skill 生态正在爆发

2026-09-30 · 约 5 分钟 · WSWIN

如果说 2024 年是提示词的年份，2025 年是 Agent 的年份，那么 2026 年很可能属于 Skill——那些让 Agent 突然"会干活"的可插拔能力包。

最近中文 X 圈子里，Skill 几乎成了最高频的词。有人做了个开源的"skill 商店" SkillNet，据博主介绍索引了 GitHub 上几十万个开源技能，你用一句话描述需求，它自动帮你匹配，装进 Claude Code 或 Codex 就能用。另一位博主更狠，直接把 180 个能让 Agent 做视频、剪视频的开源 skill 全部分类整理，还给每个打了安全评级，堪称"编程 Agent 的视频工具榜单"。

Skill 的玩法也在变得具体。一位做产品的博主分享了 5 个找产品方向的 skill：模糊想法先发散再收敛、竞品对比出定位图、市场规模交叉验证、访谈记录提炼需求、目标拆成机会树——一套组合拳下来，Agent 就能输出一页像样的产品分析。还有更垂直的：把代码仓库一键转成 Xmind 思维导图、把逆向 APK 的老手经验炼成 skill、让专利交底书自动生成。

基础设施也在跟上。一款叫 magpie 的本地网关工具在开发者圈子里刷屏：常驻菜单栏，20 多个 Agent 一键换模型，还带本地反代功能，被称为换模型工具的最强对手。而微软的 Agensh 则走了另一条路：干脆不要"AI 大管家"，让最多 1024 个 Agent 自己商量分工干活，据博主转述，AI 甚至自发长出了"评审""整合者"这样的组织角色。

看懂这个趋势的人已经开始行动了：与其收藏 100 个提示词，不如给你的 Agent 装 10 个靠谱的 skill。能力可以外挂，经验可以打包——这才是 Agent 真正开始"打工"的起点。
